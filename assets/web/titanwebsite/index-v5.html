How Titan works

Capture. Store.
Recall.

Titan watches your workflow, extracts what matters, and keeps it local — so your agent's memory stays private and fast.

01

Capture

Context emerges as you code. Titan extracts the signals worth keeping — decisions, outcomes, and preferences.

02

Store

Everything lives on your machine. No cloud sync, no external services — just a local graph of your project's history.

03

Recall

When your agent asks, Titan returns the right memory — relevant, connected, and ready to use.

Quick start

Two commands.
You're running.

Titan installs locally and runs beside your agent. No cloud account, no external dependencies.

View on GitHub
terminal 
$ pipx install 'git+https://github.com/kuwosaad/Titan-Mem.git'
# Output: Titan installed. Run `titan init` to set up.

$ titan init

$ titan doctor --agent opencode
