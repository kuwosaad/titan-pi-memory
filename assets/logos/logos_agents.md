# Logos Agent Guide

## Purpose

`assets/logos/` contains Titan logo source folders and generated logo outputs.

## Structure

- `output/`: generated logo output files moved from old `logo-output/`.
- `titan-logo/`: Titan logo source/work folder moved from old `titan-logo/`.

## Working Notes

- Prefer adding new logo work under this folder rather than creating new root-level asset folders.
- Before deleting generated logo outputs, check README/docs/web references.
