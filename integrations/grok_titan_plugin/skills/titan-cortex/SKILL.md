# Titan Cortex

Pi command: `/titan-cortex`. Grok equivalent:

```bash
titan-grok cortex 1,2 --question "how do these topics relate"
```

If cluster ids are unknown, run `titan-grok clusters` first. Treat tensions as evidence, not diagnoses.
