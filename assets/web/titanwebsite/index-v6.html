How It Works

Five stages.
Zero config.

Titan runs quietly in the background while you code. From conversation to recall, fully automated.

01
mic

Capture

Listens to your conversation events in real time via a spool plugin

02
psychology

Extract

Uses an LLM to pull out the important facts from your conversations

03
hub

Embed

Converts each memory into a vector for semantic search by meaning

04
database

Store

Saves everything locally in SQLite. Your data never leaves your machine

05
neurology

Recall

When your agent asks, Titan finds the most relevant memories instantly

Capabilities

Engineered for
how you work.

Every design decision prioritizes local-first privacy, zero-friction setup, and intelligent recall.

01 / Local-first
lock

All data stays on your machine

Everything is stored locally in SQLite. No cloud services, no database servers, no data leaving your network. Titan is designed for developers who take privacy seriously.

02 / MCP Native
cable

One-line integration

Add a single JSON block to your agent config. Titan starts capturing and recalling via stdio MCP.

03 / Semantic
manage_search

Search by meaning

Memories are embedded as vectors. Your agent finds relevant context by semantic similarity, not keyword matching.

04 / Multi-backend
swap_horiz

Use your preferred LLM

Supports Gemini, OpenAI, OpenRouter, and Ollama for memory extraction. Switch freely.

05 / Auto-Ingest
bolt

Background worker, zero triggers

Scans for new events every 3 seconds using byte-offset cursors. Deduplicates and processes incrementally. No manual intervention needed.

06 / Knowledge Graph
account_tree

Visualize your memory landscape

Built-in interactive graph visualization to explore connections between concepts and sessions. Run `titan graph --agent opencode --open` to launch.

07 / CLI
terminal

Full command-line control

`titan init`, `titan config show`, `titan mcp` -- manage everything from the terminal.

Memory Streams

Two kinds of memory.

Titan organizes what it learns into two streams, so your agent knows both what happened and what was decided.

Rough

What happened

Timelines, actions, session recaps. The narrative thread of your work over time.

"Debugged the auth middleware yesterday, issue was in the token refresh logic"
Learnings

What was decided

Preferences, patterns, facts. The durable knowledge your agent should carry forward.

"Project uses PostgreSQL, not MySQL. User prefers dark mode"
Quick Start

Running in
under a minute.

Install with pipx, set your API key, and connect your agent. No cloud setup. No configuration files.

01 Install pipx install 'git+https://github.com/kuwosaad/Titan-Mem.git'
02 Setup titan init
03 Connect titan mcp --agent opencode
opencode.json
{ "mcp": { "titan_memory": { "type": "local", "command": [ "titan", "mcp", "--agent", "opencode" ], "enabled": true } } }
