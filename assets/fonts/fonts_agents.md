# Fonts Agent Guide

## Purpose

`assets/fonts/` contains font files and font-family folders used by brand or design assets.

## Structure

- `rostex/`: Rostex font assets moved from the old root-level `rostex/` folder.

## Working Notes

- Check license and usage expectations before moving fonts into a shipped product path.
- Keep font families grouped by folder instead of placing loose font files at the repo root.
